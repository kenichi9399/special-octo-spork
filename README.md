# いきもの たからさがし 3D

小学1年生向けの、めずらしい生き物を探して変身できる3D宝探しゲームです。

## 公開方法

GitHub Pages を有効にすると、同じWi-Fiでなくてもスマホから遊べます。

1. GitHubでこのリポジトリを開く
2. Settings を開く
3. Pages を開く
4. Build and deployment で `Deploy from a branch` を選ぶ
5. Branch を `main`、folder を `/ (root)` にする
6. Save を押す

公開URLの候補:

https://kenichi9399.github.io/special-octo-spork/

## 注意

このリポジトリは public なので、GitHub Pages を有効化すると外部からアクセスできます。
